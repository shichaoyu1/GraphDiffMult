# PASA / GDI 评审驱动修改计划

日期：2026-10-09。依据：桌面 `GDI v1 opinion.md` 的两位真人评审与 AI 辅助评审、当前源码、2026-06 本地中间章节和结果 CSV。用户最新要求：先形成计划，代码直接改；本轮不改论文正文，不覆盖历史稿件。

## 1. 当前结论与修改边界

最终代码验收记录：14项合成测试通过，含8种配置的一轮假模型流程和保存后重评分；编译与diff检查通过。详见 CODE_CHANGES.md。没有真实队列重跑或正文改写。

模型迁移和研究工作规范已完成，训练与评价的科学协议此前仍是旧实现。`PASA_EVALUATION_PROTOCOL.md` 在本轮开始时只是修订草案。本轮 `semantic_evaluation.py` 与 `train_semantic_alignment.py` 已接入 `pasa_patient_metadata_v2`，包括未知掩码、Hit/真 Recall、字段/区域/患者宏平均、词表外真值分母、AUC 平分 ties、完整测试集评价和结果版本记录。严格划分、独立 sample/split 种子、冻结划分输入，以及新基线开关也已接入。**代码已接入，验证结论与实际重跑由主代理最终结果确认；新基线尚无实验数值。** 代码修改、合成验证、真实数据检查、确认性实验和论文主张更新是不同的完成状态；不能由“代码测试通过”推出“论文问题已解决”。

已经核实：正样本来源是患者结构化元数据与字段选择规则；当前原型是可学习参数；旧 Recall@k 实际为任一正样本 Hit@k；旧 anchor consistency 是正负余弦相似度间隔；历史 no_anchor 改变病理字段及评价目标；本地 CSV 的 full/no_graph 行与评审摘录的映射不同。尚未核实：正式投稿快照与本地中间稿之间的版本关系、每个历史运行的实际病例划分、外部队列重复数字是否独立计算。

因此修订主问题建议为：**在患者属性监督下，区域 MRI 表征是否比匹配的全局表征更有利于已记录患者属性的检索与表示学习？** 区域规则只形成辅助任务。区域组织学对应、临床解释正确性、分级改善、跨域病理泛化均须各自新增证据。图与扩散是否必要由对照决定，不能为了保留长管线而先规定结论。

## 3. 正样本构建必须进入主文的内容

本轮计划将以下内容变成标签规范及可导出记录，未来主文按同一规范撰写，避免代码与叙述分离。

1. 原始来源：Tumor Grade、Tumor Type、IDH、MGMT、1p19Q CODEL 来自患者记录；来源系统、标本采集时间、规范化映射及冲突处理另列数据字典。年龄/性别为可选临床字段，不能称为病理证据。
2. 表示：键为字段与规范化取值组合，原型为随机初始化后学习的向量；不声称有未实现的文本编码器、自由文本抽取或切片编码器。
3. 区域构建：明确掩膜来源、是否人工或分割模型、空区域处理、池化与节点名称。MRI 区域名称不自动变成该区域组织学标注。
4. 目标政策：患者属性主任务中多个区域可共享同一患者字段；region_rules 辅助任务根据节点名称选字段，造成不同目标。解释“不同正集”来自规则，而不是区域独立测量。
5. 缺失和词表：训练集建词表；冻结后测试真值不在词表时计覆盖/未命中，不能通过删除真值扩大成功率；缺失不当负样本。主任务不静默进行选字段全缺失后的全字段回退。
6. 成本：分开记录既有临床检测/诊疗记录成本、数据授权和去标识成本、字段整理及质控人时、MRI 掩膜成本、规则审查成本、计算成本。程序自动生成正集不等于整个监督来源“零成本”；没有实际工时/费用日志时只报构成及未计量状态。

### 完全合成的患者例子

病例 SYN-001：Grade=4、Tumor Type=Glioblastoma、IDH=wildtype、MGMT=unknown、1p19Q=non-codeleted。这不是临床病例，也不是独立区域标签。

| 查询 | 旧 region_rules 正集 | 已知但规则未选 | 缺失字段 |
|---|---|---|---|
| enhancing | grade::4；type::glioblastoma | IDH、1p19Q | MGMT |
| edema | idh::wildtype；type::glioblastoma；grade::4 | 1p19Q | MGMT |
| necrotic/core | grade::4；1p19q::non-codeleted；type::glioblastoma | IDH | MGMT |

表中为便于阅读的简写，实际键沿用源码 `tumor_grade::4`、`tumor_type::glioblastoma`、`idh::wildtype`、`1p19q_codel::non-codeleted`。患者属性主任务的三个区域均继承四个已知属性；MGMT 所有候选屏蔽。字段内明确互斥的其他值可作负例；未证明互斥、多标签或冲突字段不自动作负例。region_rules 未选 IDH 只表示规则未给该关系监督，不能称为 biological negative。

这解释监督怎么来，并不能证明增强/水肿/坏死三个区域分别含对应分子病理。若无空间配准组织学或适配的独立区域标注，论文需停留在患者属性关联层。

## 4. 当前代码修订应实现的行为

接入状态：`semantic_evaluation.py` 提供版本化监督/评价与严格划分验证；训练入口接入固定分子主终点、完整集评价、`protocol.json` 的覆盖率及源码 hash。`no_anchor_loss`、`global_clip`、`multilabel` 和 `single_positive` 为新对照入口；full/no_anchor 在默认分子终点上共享评价定义。bootstrap 工具隔离 v1/v2，不能混用不同版本汇总。下列条目仍作为验收要求，不能仅凭存在开关判定科学行为全部正确。

- 明确 legacy 与 protocol_v2，结果文件携带版本，历史分数不与新协议混报。
- 在训练和评价各自规定目标及可确认负集；保留未知掩码，避免“未选字段”和“缺失字段”进入负集。未知字段在 log-sum-exp 分母中的处理须同步检查，不能只修评价。
- Hit@k 定义为至少一个正例命中；Recall@k 定义为命中真阳性数/冻结真阳性总数；保存有效候选数、全部真阳性数、词表内真阳性数。MRR 说明排名对象及无命中计零；无真阳性查询不评分但报告数量。
- 相似度间隔命名为 similarity gap，AUC 只用已确认正负；全正/无负查询标记不可估计并报覆盖。字段/患者平均与历史 query-micro 明确分开。
- 默认聚合为患者内部先区域、再字段、最后患者等权，避免区域多的患者得到更多权重；缺失层不补伪零。确认性区间以患者成对重采样，保留全部区域/seed，标明只覆盖固定训练模型的患者抽样不确定性。
- 空 splits 立即报错；检查跨集合患者 ID 重叠与集合内部重复；记录采样、split、training 的种子和病例 ID。
- 保存 source/config/labels/gallery/splits 的版本、checkpoint 选模规则、每患者预测、缺失/OOV/回退统计和正集 provenance。若旧输出缺必要数据，不能假装新指标已由历史汇总值复原。

合成验收应涵盖：两个正例只命中一个时 Hit=1 而 Recall=0.5；未知候选先屏蔽再排名；词表外真阳性不从 Recall 分母移除；无真值不计成功；已知正例未命中计零；无负集 AUC 不可估计；患者区域数不同仍等权；划分为空、交集、重复 ID 均失败。上述是科学语义验收，不是重跑结果。

## 5. 最低必要实验矩阵

确认性对比共享一次冻结患者划分、字段规范/词表、有效样本、输入条件、训练/调参预算和验证选模；每个模型保存参数数量、训练时间与逐 seed 输出。参考标签只用于监督、选模和离线评分，不能经真值正集构造测试时模型输入。

| 对照 | 回答的问题 | 关键约束 |
|---|---|---|
| 同编码器全局 MRI embedding + 同检索头 | 区域表示相对全局表示是否必要 | 已接入 global_clip，实际是区域特征均值的患者全局查询，不等同整幅输入global；不用额外真值候选 |
| 同编码器、字段级多标签/多任务分类器 | 原型检索相对直接属性预测是否有益 | 已接入 multilabel masked BCE，当前仍为同原型打分头；是内部受控loss基线，不自动等同独立常规分类器 |
| 最小 semantic-unit + anchor retrieval | 不用 graph/diffusion 是否已经充分 | no_graph 仍可能保留 diffusion，不能代替同时移除两者的最小单元 |
| 频率/先验、unit-type-only | 是否可凭标签频率或节点名称完成任务 | 只由训练数据拟合，不读取测试患者 metadata |
| single-positive vs multi-positive | 多正例学习是否改善覆盖 | 已接入 objective；单正例选取及未选真阳性掩码须验证，anchor-center是否仍用多正例也须说明；两者评价同一完整正集 |
| 固定查询下的 region-rule vs patient-label | 规则是否改善监督或只是改变任务难度 | 不比较不同标签定义上的裸分；共同属性评价，规则任务另报 |
| image/region 打乱、type-only 与区域池化控制 | 是否利用患者影像而非名字/全局泄漏捷径 | 打乱配对、区域错配是预设诊断；区域类型自带标签不算独立证据 |
| 同条件 +graph / -graph；+diffusion / -diffusion | 辅助模块增益是否成立 | 其他损失、私有分支、预算保持一致；全因子或单一开关 |

no_anchor 不作为“去掉原型”或“无监督”的模糊对照。分别设计：冻结表示后共同探针；共同分子主任务有/无病理辅助监督；或同检索任务只把 lambda_anchor 置零。三者估计不同机制，各自命名。让无监督对照检索没训练的随机原型不能修复公平性。

建议先完成全局、多标签、最小单元与频率/type-only，判断主机制是否值得确认，再增加图/扩散。若最小单元表现足够或辅助模块持续负面，则主方法保留最小有用部分；复杂度不作为贡献证明。分级/分子 MRI-only 下游分析可检验表征实用性，但不替代区域对应验证。

## 6. 历史数值与版本纠错计划

本地 `sota_comparison_table.csv` 的 20260511 三种子汇总是：no_graph Hit@1=0.7800、MRR=0.8750、Pair AUC=0.8934、similarity gap=0.4063；full 对应 0.7222、0.8324、0.8480、0.2932。这些可核对本地 CSV，**尚未据原始运行独立重算，也不证明正式稿应该机械换行**。

评审摘录将 full/no_graph 映射为相反方向。本地 20260617 中间章节已经写 no_graph 优于 full；差异可能涉及稿件或生成表版本。建立 `稿件表行 → 生成脚本 → run directory → config variant → checkpoint → patient predictions` 链，逐行确认。确认后只生成带新版本的纠错表，旧证据保留。

13 个 round-seed 为 20260506/08/11 的 5+5+3 开发配对，不是13独立随机种子，也不是同一冻结协议的13重复。三种子子集称为明确日期的开发子集，不以“稳定化”掩盖筛选规则；公开是否更改超参/数据/代码及选择依据。旧 full/no_anchor 差 0.131 只保留为不同监督与评价设置的历史描述，不能继续称同任务因果消融。患者数量及 run ID 必须从真实记录提取，不能从评语补齐。

外部252例来自评审描述，其纳排与样本清单仍须核实。BraTS 相似度间隔0.4467/MRR0.9234和0.3083/0.5620不能因为外部表也出现就算独立证据。外部无逐患者原始输出和运行配置时该项标记未验证，不参与跨域优势主张。BraTS 体积规则 proxy 不能等同真实病理分子监督；“ceiling”要按记录补具体数值与正集/候选规模，若无可追溯数字则不造1.000。

## 7. 数学与叙事修改的未来方案

方法章节未来按“实际输入/区域构建 → 字段来源与原型 → 正负未知 → 全局候选 → 训练损失 → 推理不读取真值 → 指标/汇总”排列，完整患者例子留主文。图、扩散与附加损失放在核心之后，逐个给实现对应式，旧抽象稿的 Laplacian/centroid 式不能冒充现有源码全部损失。

centroid 残差只去掉一个方向，不能称删除全部共享语义或识别 MRI-specific information；改作 centroid-relative residual diagnostic。若真要删除锚点张成子空间，需另行定义数值稳定的投影、秩及对照，且投影也不自动证明特有信息。正集概率总和提升不证明 cooperative synergy，改作 positive-set probability change 并报告各正例变化；需要独立可识别的交互实验才谈协同。

临床可核验、grounding、semantic stability、SOTA 和跨域优势的每项声明须绑定适配证据。模型余弦一致、训练损失降低、模型自选 top-k 均不足以独立验证生物学意义。相关工作要核查评审提到的 MGCA/RadZero 原文与实际比较条件，本计划没有外网查证，不将评审引用自动写入参考文献。内部 pmcclip_style/biomedica_style/medclip_style 需逐版本对齐名称，写成内部适配而非公开系统复现。
