# 2026-10-19 服务器实验结果与 AAAI 评审对应审计

## 判断

新实验显著改善了可追溯性和对照覆盖，但尚不支持完整 PASA 的性能优势、区域级病理对应，或图/扩散的必要性。当前最强证据是：在这组 UTSW 患者级元数据监督任务中，完整 PASA 的字段内首位检索退化为训练标签频率选择；简单全局模型及部分近期方法适配优于完整 PASA。连续分数仍含部分患者区分信息，不能把首位预测退化等同于全部表征没有信息。

这是对返回结果的审计，没有训练新模型、改写原结果或修改文章。数据目录为 `output/20261019_AAAI_review/sota_baline_output`；评审来源为用户桌面的 `GDI v1 opinion.md`。仍未核实正式投稿 PDF 与历史结果表的逐格来源。

## 审计范围与可信程度

- `pasa_v2_20261009_1707`：12 个 core + 15 个 ablation，共 27 个正式运行，均有 test_metrics 和 complete 记录。
- `sota_alignmentv2_20261009`：6 方法 × 3 训练种子，共 18 个正式运行，均有完成记录，每次 30 轮。
- `pasa_v2_20261009` 与 `sota_alignment_20261009` 是前期 smoke/未完成尝试目录，不能作为额外独立正式重复。第一目录只发现一个带 test_metrics 的 smoke 运行。
- 四个目录的根级划分均为 train 438、validation 63、test 124，ID 集合内部的训练/验证/测试交集为零。这是患者 ID 层检查，不等于已审计原始影像重复或患者身份映射。
- 第一轮 27 个正式运行从保存的向量和目标重算 Hit@1、mAP、MRR、Pair AUC；第二轮 18 个从逐患者分数重算上述指标，并另核对跨患者分子 AUROC，全部与保存结果一致（数值容差内）。
- 第二轮全部冻结源码哈希对应 git `b4cfc9c` 的源码。第一轮源码也能在 `b4cfc9c` / `69f1e10` 中找到对应版本。当前 JSON 格式补丁和 Windows 换行差异不能误判为实验源码失控。
- 两轮评价聚合不同：第一轮 region→field→patient；第二轮先汇总患者分数再 field→patient。分别报告，不直接拼成一张共同排名表。
- 三个 seed 主要描述同一患者划分上的训练波动，不是三个独立机构或三个独立测试队列。

## 第一轮：核心机制与消融

以下为三个训练种子的算术均值，未宣称显著性。

| 方法 | Hit@1 | mAP | 解释 |
|---|---:|---:|---|
| pooled_global | 0.7742 | 0.8871 | 同一任务下简单全局表示的均值最高 |
| unit_multilabel | 0.7497 | 0.8749 | 未显示检索目标优于分类目标 |
| unit_single_positive | 0.7461 | 0.8731 | 与多正样本检索几乎相同 |
| unit_retrieval | 0.7458 | 0.8729 | 尚未体现局部单元优势 |
| full | 0.7446 | 0.8723 | 三个 seed 的这两个指标完全一致 |
| without_graph | 0.7478 | 0.8739 | 三个配对 seed 中两个更高、一个相同 |
| without_center_loss | 0.7446 | 0.8723 | 未体现中心损失的检索收益 |
| without_pathology_supervision | 0.7446 | 0.8723 | 未体现增加该组标签监督的检索收益 |
| without_diffusion | 0.7413 | 0.8707 | 两个 seed 相同，仅一个下降；不足以证明稳定收益 |

`without_pathology_supervision` 实际排除 Tumor Grade / Tumor Type，仍保留分子监督，不是“完全没有临床标签”的对照。不能据此声称所有病理/分子监督无效。

full 的正负余弦间隔均值 0.1977，无图为 0.1871；这只能说明该几何量不同，不能解释为区域病理准确性或跨运行语义稳定性提高。新结果不能自动解释旧表格与旧正文的矛盾；旧数字仍需查来源并明确撤换。

## 第二轮：近期方法适配对比

同一协议下三个种子的均值。生物标志物宏 AUROC 是三个字段的跨患者 AUROC 均值，不是旧 Pair AUC。

| 方法 | Hit@1 | mAP | 生物标志物宏 AUROC |
|---|---:|---:|---:|
| 训练集频率（不看 MRI） | 0.7446 | 0.8723 | 0.5000 |
| PASA full | 0.7446 | 0.8723 | 0.6150 |
| PASA minimal | 0.7446 | 0.8723 | 0.6623 |
| PASA text control | 0.7446 | 0.8723 | 0.6034 |
| 全局图像—文本余弦 text_cosine | 0.7997 | 0.8999 | 0.6555 |
| CARZero metadata adaptation | 0.7697 | 0.8849 | 0.6765 |
| RadZero metadata adaptation | 0.8015 | 0.9008 | 0.6552 |

这些对照采用近期方法的对齐模块，并统一适配 MRI 和结构化元数据；不是原论文完整系统、原始报告数据、官方预训练权重的直接复现，也不能写为“击败原论文 SOTA”。全局 text_cosine 仍使用 MRI，不是纯文本预测器。

探索性患者配对 bootstrap：先对三个固定训练种子的患者得分取均值，再对 124 个患者重采样 10,000 次。相对 PASA full 的 Hit@1 差值：

- text_cosine：+0.0551，95% percentile 区间 [0.0166, 0.0945]。
- RadZero adaptation：+0.0569，[0.0125, 0.1026]。
- CARZero adaptation：+0.0251，[-0.0076, 0.0600]。

这些是结果后审计，条件于当前划分和已训练模型，未校正多重比较，也未包含训练过程全部不确定性。可以作为当前设置下差异的描述，不能替代独立确认实验。

## 最关键的诊断

### 1. 首位答案完全等于频率基线

PASA full / minimal / text control 共 9 个正式运行，每个运行的全部 231 条可评患者—字段记录，其 top-1 均与训练频率基线相同：

- IDH：124/124 预测 wild type。
- MGMT：51/51 预测 unmethylated。
- 1p19Q：56/56 预测 non co-deleted。

这已经从保存的预测逐条核实，并非仅因总分恰好一致而作的推测。完整模型宏 AUROC 高于 0.5 表明连续分数并非全部常数；例如 PASA full 的 IDH AUROC 三个 seed 为 0.6974、0.8757、0.7225。可以说有一定患者排序信息，但首位检索尚未利用这种信息超越频率基线。

### 2. 多个检索指标在当前候选空间下实质重复

每个已知分子字段有两个候选、一个正标签。因此在这些结果里：

- mAP = MRR = (1 + Hit@1) / 2。
- 无分数并列时字段内 Pair AUC = Hit@1。
- Hit@5 / Hit@10 恒为 1。

所以 mAP 0.8723 并不是另一个独立的强证据。不看 MRI 的频率基线也达到这一分数。保留多个数字不会增加结论的证据数量。

### 3. 选模停留在很早的 epoch

训练器仅在 validation mAP 严格变大时更新 best.pt。PASA full 的最终选模轮次由 history 推得为 [2, 1, 1]；minimal 和 text control 均为 [1, 1, 1]。后两组全部 30 轮 validation mAP 不变。

因此“每个模型训练 30 轮”不等于“报告第 30 轮模型”。当前离散检索指标不能分辨未跨越类别边界的排序改善。选模口径可能限制了结果，但目前没有证据证明更换选模指标就会使 PASA 优于基线。只能在验证集上诊断，不能从测试集挑选有利 checkpoint。

### 4. 分子标签覆盖有限

124 个测试患者共 372 个潜在患者—字段记录，实际 231 个可评价、141 个缺失并跳过（约 37.9%）。IDH 124 人，MGMT 51 人，1p19Q 56 人；三个字段样本量不同。当前无 OOV 正标签。

所有方法的 MGMT 跨患者 AUROC 均值表现薄弱，不能用总体平均掩盖字段差异。多个方法的 IDH 表现明显更好，值得后续针对性诊断，但当前不能事后把 IDH 改称预先指定的主要终点。

## 后续优先级

1. 先暂停同配置的大规模追加训练。现有结果已足够发现主要问题；不是缺几个 seed。
2. 用验证集检查每字段分数分布、少数类召回、验证 AUROC 随 epoch 的变化、损失项尺度及梯度、选模规则。先做小规模诊断，不从测试集挑模型。
3. 以简单全局模型为必须超过的对照；检验单位级多正样本损失和标签频率是否推动单类首位预测。损失/类别平衡/聚合的解释目前是待检验假设。
4. 明确下一轮主要任务与终点。若研究患者分子预测，应围绕跨患者 AUROC、类别平衡指标及校准；若研究区域对应，应先解决独立区域参考标准。调整必须记录为新开发版本。
5. 图与扩散若继续没有可靠增量，简化方法或作为附加诊断。当前结果不支持以两者为核心性能创新。
6. 当前测试集已用于这些决策，后续改进需披露开发使用，最终确认优先采用未参与决策的数据或预先锁定的外部评估。

这 45 个正式运行的价值是明确了可重复的失败模式与论文主张边界。现阶段可以写出更透明的实验与限制，尚不能据此写成“PASA 的复杂组合与病理对应均获证实”。
