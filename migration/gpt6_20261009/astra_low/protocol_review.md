# PASA_EVALUATION_PROTOCOL.md 额外复核

本文件在独立 audit.md 完成后生成，未据此修改独立审计。复核范围仅根目录协议 v0.1（2026-10-09）。总体：合成正样本、三态标签、可比任务、代理边界及中心交叠表述与源码审计相符；未发现需推翻协议方向的错误。建议在冻结前补足以下操作定义。

1. **消融估计目标仍需明确（协议:42）。**“相同输出头、相同训练标签”若包含全部病理标签，则两组都受到病理监督，不能再称有无病理监督的对照。建议区分：(a) 冻结表征后使用相同探针，测表示质量；(b) 共同分子主任务加/不加病理辅助监督，测辅助监督贡献；(c) 同一任务仅去 anchor loss，测损失项贡献。各自固定查询和候选，名称、主张与被干预因素对应。现文没有错误地声称探针无监督，但任务归因仍有歧义。

2. **MRR 与平均规则需写完整（协议:50、56）。**首个正标签的倒数排名是单查询 RR，MRR 是其指定加权平均。应规定字段→区域→患者→队列的具体聚合顺序，以及无正标签字段如何计覆盖率、是否排除；否则相同逐查询分数可能产生不同主结果。AUC 同样需固定逐字段/逐查询宏平均或池化方式，避免跨字段分数尺度影响 pooled AUC（协议:54）。

3. **未见标签与候选覆盖需指定主要估计量（协议:24、40、49）。**协议已正确禁止按排名缩小召回分母，但训练词表外正标签如何进入固定主任务还需明确：若采用完整真值分母，它们保留为未命中；另可报告词表内条件表现，但须明确分开，不能先丢标签后把 Recall 报成总体性能。候选必须可被模型有效打分，不能为补齐词表加入随机向量。正集合和评价范围应在排名前冻结。

4. **多种子统计仍需落实（协议:56）。**患者 bootstrap 处理患者抽样变异，不自动覆盖训练随机性、不同划分和开发轮次依赖。建议固定确认 split，逐训练 seed 报告配对差；明确主要推断是固定模型上的患者泛化，还是训练程序平均效果。后者应说明种子与患者的分层重采样或其他设计，禁止把同一患者×种子的记录当独立样本。现协议已有开发/确认区分，是正确方向。

5. **单等级中心评价边界应直接落到指标（协议:62）。**留出仅高等级中心可报告该等级敏感度/检索表现，无法估计完整分级区分、二分类 AUROC 和低等级特异度；中心探针可预测性证明表征含中心信息，不能单独证明决策依赖中心。建议在验收模板中增加不可估计标记和共同支持表，而非仅文字提醒。

以上为冻结前的定义补充；本次未训练、未读取真实患者，也未确认该协议已接入运行管线。
